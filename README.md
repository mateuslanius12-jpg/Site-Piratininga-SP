# Piratininga SP — Site

Site estático preparado para GitHub Pages.

## Arquivos
- `index.html` — página principal
- `style.css` — visual preto/vermelho
- `script.js` — menu mobile e funções temporárias
- `assets/banner-conexao.png` — banner enviado
- `assets/logo-piratininga.png` — imagem enviada

## Como publicar no GitHub Pages

1. Crie uma conta em https://github.com/ se ainda não tiver.
2. Clique em **New repository**.
3. Nome sugerido: `piratininga-sp`.
4. Pode deixar como **Public**.
5. Envie todos os arquivos desta pasta mantendo a pasta `assets`.
6. No repositório, entre em **Settings → Pages**.
7. Em **Build and deployment**, escolha **Deploy from a branch**.
8. Selecione `main` e a pasta `/ (root)`.
9. Salve.
10. O GitHub vai gerar o endereço do site.

Depois podemos trocar o endereço gratuito pelo domínio próprio quando você tiver um.
